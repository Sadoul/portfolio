# Портфолио · чёрно-белый скетч-стиль

Статический сайт-портфолио с 3D-барабаном-навигацией. Без сборки —
чистые HTML/CSS/JS, готов для GitHub Pages.

## Разделы (вкладки барабана)
1. **Web** — Full-Stack / веб-проекты
2. **Minecraft** — плагины, сборки, карты
3. **Gamedev** — Game Development
4. ~~Systems~~ — системное программирование (скрыта, неактивна)

Барабан **цикличный** — крутится бесконечно в обе стороны.

## Управление барабаном
- **Скролл** над барабаном — крутит
- **Клик** по левой/правой карточке — крутит в её сторону
- **Стрелки** ← → на клавиатуре
- **Свайп** влево/вправо на мобильном
- **Перетаскивание** мышью по горизонтали
- Кнопки ◀ ▶ по бокам

## Как заменить медиа и ссылки
Всё редактируется в **`js/data.js`**.

Каждый проект — объект:
```js
{ title:'Название', type:'video', src:'assets/web/my.mp4', link:'https://...', desc:'Описание' }
```
- `type`: `'video'` | `'photo'` | `'gif'` (пока файла нет — рисуется скетч-заглушка)
- `src`: путь к файлу (положите файлы в `assets/<раздел>/`) или `null`
- `link`: URL проекта или `null` (тогда покажется серая «ссылка пока недоступна»)

### Структура медиа
```
assets/
  web/     ← видео/фото/гифки для раздела Web
  mc/      ← для Minecraft
  game/    ← для Gamedev
```
Папки уже созданы (см. `.gitkeep`). Кладите файлы и прописывайте пути в `data.js`.

## Как включить 4-ю вкладку «Systems»
В `js/data.js` в массиве `TABS` у вкладки `sys` поставьте `active: true`
и добавьте проекты в `PROJECTS.sys`.

## Запуск локально
Откройте `index.html` в браузере, либо:
```
python -m http.server 8000
```
и откройте `http://localhost:8000`.

## Публикация на GitHub Pages
1. Репозиторий уже запушен (ветка `main`).
2. На GitHub: **Settings → Pages → Source = Deploy from a branch → `main` / `/ (root)`**.
3. Через минуту сайт будет доступен по адресу:
   `https://<ваш-ник>.github.io/<имя-репозитория>/`

## Технологии
- HTML5, CSS3 (3D Transforms, `preserve-3d`), ванильный JS
- Шрифты: Caveat / Patrick Hand / Kalam (Google Fonts)
- Без фреймворков, без сборки, без зависимостей
